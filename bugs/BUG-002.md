# BUG-002 — No empty-state message for unsuccessful searches

**Severity:** Low  
**Priority:** Medium  
**Status:** Open  
**Area:** Transaction search

## Steps to reproduce
1. Log in.
2. Enter a search term that does not match any transaction, such as `xyz-not-found`.

## Expected result
The UI displays a clear message such as “No transactions found.”

## Actual result
The table becomes empty with no explanatory message.

## Recommendation
Display an empty-state message when the filtered result set is empty.
