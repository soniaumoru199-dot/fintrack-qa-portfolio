# BUG-001 — Negative transaction amount can be submitted

**Severity:** Medium  
**Priority:** High  
**Status:** Open  
**Area:** Transaction form

## Description
The amount input has a minimum of 1, but the client-side JavaScript only checks whether the amount is truthy. A negative amount can therefore be inserted programmatically or through manipulated input and may affect financial totals incorrectly.

## Preconditions
User is logged in.

## Steps to reproduce
1. Open the dashboard.
2. Set the transaction amount to `-5000` using browser developer tools or script injection.
3. Submit the transaction.

## Expected result
The application rejects negative amounts and displays a validation message.

## Actual result
The transaction can be added and can alter the displayed totals.

## Recommendation
Validate that amount is a number greater than or equal to 1 on the client and server before accepting the transaction.
